Explanation of the two algorithms

These explanations are written in simple English for TU BCA viva.

Algorithm 1: Tour Recommendation Algorithm

This algorithm suggests tour packages to the user. First, the system checks the booking history of the user. It finds which category the user likes most, such as Adventure, Cultural or Wildlife. Then it also checks the season and the average budget of past bookings.

After that, the algorithm compares all available tour packages. If a package matches the user’s preferred category, it gets more score. If the season is similar, it gets extra score. Featured packages also get extra score. If the package price is close to the user’s average budget, the score becomes higher. Finally, the packages are sorted by score and the top results are shown.

In viva you can say:

“This algorithm recommends the most suitable tour packages by analyzing the user’s previous interest, budget and travel preference.”

Algorithm 2: Smart Trip Cost Estimation

This algorithm calculates the total estimated cost of a trip. It starts from the base package price. Then it multiplies the base package price by the number of travelers. After that, it adds transport cost, hotel cost and meal cost according to the options selected by the user.

If the traveler count is larger, the algorithm also gives a group discount. So the final amount becomes more practical and realistic for group tours. This helps the user know the estimated trip cost before making payment.

In viva you can say:

“This algorithm automatically estimates the full travel cost based on the selected package, number of travelers, transport, hotel and food plan.”
